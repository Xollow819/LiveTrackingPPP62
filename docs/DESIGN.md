# Tidal glass — PPPVenza

Field practicals need a readable map, an honest sharing indicator and evidence that survives poor connectivity. The Golden Gate Liquid Glass reference informs the floating chrome; the route and records carry the visual hierarchy.

Palette: Porcelain #F5F7FA; Ink #142432; Bay Blue #0A84FF; Tide #0B756F; Amber #C98232; Night #0C141F. Instrument Sans is bundled under OFL. Blue identifies action, teal successful sync, amber exceptions. State also has a text label.

Glass layers: circular map controls, capsule navigation, more diffuse panels for text. Text-entry fields and records use opaque surfaces. Thin highlights, 20–28dp optical corners, minimal dispersion and restrained shadows. Background content is captured explicitly through Haze Sources. No experimental platform backdrop. Older Android and reduced transparency use tinted, bordered fallback surfaces. No essential state depends on an optical effect.

Purposeful motion only: pressed controls, expanding search, changing tabs, collapsing help. Respect system animation scale. Minimum 48dp controls, sentence case labels, content descriptions, scrollable keyboard-safe forms and large-font layouts. Never show “online” solely because a session exists.

Review gates: map capture visible behind glass, text readable on bright/dark satellite scenes, GPS below search, no overlapping controls or attribution, no fake metrics. Compare welcome, auth, setup, map, checkpoint, check-in, roster, records, history and preferences in light/dark and large-font configurations. A physical-device performance pass is required before claiming sustained 60fps.
